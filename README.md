## About

I work across the whole stack: core engines, command line tools, APIs, and the interfaces around them, usually in a single monorepo with continuous integration wired in from the first commit. Most of my recent work sits where AI systems meet real products: agent integrations, context design, and the plumbing that keeps them bounded and honest.

I care about software that is truthful about what it does and does not do yet. Failing closed instead of guessing, treating anything a model or a provider returns as untrusted, and never shipping a claim the code cannot back.

## Featured project

### [OpenLimiter](https://github.com/lucaswebsystems/openlimiter) · [openlimiter.com](https://openlimiter.com)

[![CI](https://github.com/lucaswebsystems/openlimiter/actions/workflows/ci.yml/badge.svg)](https://github.com/lucaswebsystems/openlimiter/actions/workflows/ci.yml)
[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](https://github.com/lucaswebsystems/openlimiter/blob/main/LICENSE)
[![Release](https://img.shields.io/github/v/release/lucaswebsystems/openlimiter)](https://github.com/lucaswebsystems/openlimiter/releases/latest)

An open source, cross platform, local first quota meter for AI coding subscriptions. When you hold several at once, the scarce resource stops being money and becomes quota. OpenLimiter reads what is already on your machine and hands your coding agent a bounded picture of the budget it has left.

- **Agent native.** A statusline for you and a bounded context block for the agent, inside an explicit untrusted data boundary. Enum codes, numbers and timestamps only, never provider prose.
- **Ships as a CLI, a desktop tray application, and a browser app** that installs to a phone home screen and runs offline.
- **Honest by construction.** Every connector ships labelled, and missing input becomes unknown, never a fabricated zero.
- **Zero third party runtime dependencies**, zero telemetry, no accounts, no server.
